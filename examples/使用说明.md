# 工作台示例数据

这些文件全部为程序生成的虚构测试数据。CSV 和同名 XLSX 内容相同，选择一种上传即可，不需要重复导入。表头均为单行中文字段。

## 使用方法

在工作台中先选择或创建项目，再进入“数据集”上传文件，打开数据集后进入分析或可视化页面。先试 01_销售经营数据.xlsx。

## 01_销售经营数据

72 行。柱状图：区域 / 销售额 / 求和；饼图同上。折线图：日期 / 销售额 / 求和 / 横轴升序。散点图：订单数 / 销售额。所有金额均为虚构人民币元。

## 02_网站运营数据

90 行。折线图：日期 / 访问次数 / 求和；饼图：渠道 / 访问次数 / 求和。散点图：注册人数 / 付费人数。可按渠道筛选。费用单位为虚构人民币元。

## 03_设备监测_清洗练习

50 行，故意含 2 条重复行、2 个温度缺失值、1 个湿度缺失值、1 个 85°C 温度异常值；位置偏差有正有负。先去重：50 → 48 行；再对温度、湿度分别用均值或中位数填充。温度 IQR 处理建议填充后另做一步。散点图：电压 / 电流；柱状图：设备 / 温度 / 平均值。饼图可选设备 / 计数，不能对含负数的位置偏差求和画饼图。单位：温度°C、湿度%、电压V、电流A、偏差mm。

## 核对点

销售数据销售额合计：1,435,680 元。该文件没有缺失值或重复行。设备清洗数据原始 50 行，去重后 48 行。折线图按横轴升序；散点图不做分组聚合，最多显示点数受设置限制。数值相关性不代表因果关系。

日期和时间特意存为可排序文本，保证当前上传与清洗流程一致。先不要将它们转换为日期类型后再画分类轴图，以免自行改变数据含义。所有图表以实际选择的字段、版本、筛选条件为准。

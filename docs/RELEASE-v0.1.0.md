# v0.1.0 — 首个公开版本

数据工作台支持从文件导入到统计、绘图、AI 解读和报告保存的完整操作。

本版本提供注册登录、项目隔离、CSV/XLSX、数据清洗与版本恢复、六类图表、分析计划确认、SSE 解读和报告草稿。附实际操作录屏、页面截图、部署配置和 MIT 许可证。

本地检查通过：前后端构建、4 项 Node 测试、6 项 Python 测试和 1 项浏览器流程。当前未在 Docker 和公网服务器验收。分析任务同步执行，数据采用单进程 JSON 或 MySQL JSON 快照；不支持横向扩容。

下载源码后按 README 本地启动；有服务器时按 docs/DEPLOY.md 配置。模型密钥可选，无密钥时显示演示解读。不要将个人 .env、上传文件和状态数据放入公开仓库。

# 演示步骤

先按 README 启动三个服务。完整演示约 147 秒，展示以下实际操作；不配置模型密钥也能完成计算，界面会明确标注演示解读。

1. 注册或登录，新建“销售经营分析”项目。
2. 在数据集页面上传 [销售经营演示.csv](../examples/demos/销售经营演示.csv)。该文件在 72 行销售示例中额外复制一行，专用于演示去重，导入后共 73 行。
3. 到数据清洗，加入“删除重复行”，执行并保存 V2。结果应为 72 行，原版本仍可查看。
4. 在探索分析运行描述统计，再到可视化工作室选择区域、销售额、求和，设置“各区域销售额”并保存图表。
5. 到业务资料上传 [销售指标与统计口径](../examples/knowledge/01_销售经营/01_销售指标与统计口径.md) 和 [区域与产品分析规则](../examples/knowledge/01_销售经营/02_区域与产品分析规则.md)，等待“可引用”。
6. 在 AI 分析助手开启业务资料引用，提问“按区域对比销售额，说明口径。用简短纯文本回答，不用表格。”查看区域、销售额、求和的计划及检索资料，再确认执行。
7. 核对华北 526,080、华南 478,560、华东 431,040，合计 1,435,680。点击来源编号查看原文。销售额为退款前金额；资料没有提供区域目标，不判断是否达标，也不自行添加币种。
8. 到报告中心填写摘要、勾选已保存图表并保存草稿。可通过浏览器打印为 PDF，录屏未展示打印操作。
9. 回到总览核对 1 个数据集、2 个任务、1 个图表、1 份报告。

本次完整录屏使用已配置的模型接口生成解读；资料使用关键词检索，没有启用 Embeddings。统计结果由 Python 程序计算，模型不替代原始结果。页面操作保持原速，录制浏览器视口为 1440 × 960。

README 的核心预览暂保留原版。新录制的完整视频为 `docs/videos/workflow-full.mp4`，静态页面为 `docs/images/` 中的 PNG。新的核心预览待本地确认后再替换。

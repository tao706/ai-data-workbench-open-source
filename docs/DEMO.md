# 演示步骤

先按 README 启动三个服务。以下步骤只需本地示例数据，不需要模型密钥。

1. 注册一个账号，新建“销售经营分析”项目。
2. 在数据集页面点击“导入示例数据”，得到 12 行销售数据。
3. 在探索分析中运行描述统计，核对字段与数值。
4. 在可视化工作室选择柱状图：维度为“月份”，指标为“销售额”，聚合为“求和”。标题填“月度销售额”，保存图表。
5. 在 AI 助手输入“按月份对比销售额”，生成计划，检查字段后确认执行。未配置密钥时显示演示解读；统计表来自实际计算。
6. 到报告中心填写摘要，勾选已保存图表，保存草稿；可通过浏览器打印为 PDF。
7. 刷新页面，确认图表和报告仍存在；到任务监控查看执行记录。
